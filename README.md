## Requirements

- MATLAB 

## Setup

1. Download or clone this repository.
2. Place all `.m` and `.xlsx` files in the same directory, unless the scripts specify different paths.
3. Open MATLAB and set this directory as the current folder.
4. Check that any required toolboxes are installed.

## Usage

The exact run order and input requirements should be confirmed from the scripts. To get started:

1. Open each `.m` file and check its comments, function definition, and expected inputs.
2. Confirm which script is the entry point and whether any script depends on another.
3. Confirm how the Excel files are read and whether their names or locations are hard-coded.
4. Run the appropriate script from the MATLAB Command Window or Editor.

Example:

```matlab
% Replace this with the confirmed entry-point script
run('script_name.m')
```
